    PHP shipped emergency fixes for two remote code execution bugs, together called PHP2Shell and each rated 9.2, after details and exploit code leaked early.   • Certificate authority eMudhra quits TLS after using a private key of 4

    eMudhra issued eight intermediate TLS certificates so weak that anyone could create certificates for any website or mail server. One had a private key of just 4. The certificate authority now says it is leaving the TLS business.
