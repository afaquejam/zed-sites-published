  • Tampered Claude Code extension in Cursor's marketplace exposed up to 5,000 developers

    An attacker got into Cursor's extension marketplace and published a tampered Claude Code 2.1.313 that planted SSH keys and remote access on developer machines. It stayed up for nearly 12 hours before Cursor removed it, rotated its keys and rebuilt the marketplace.
    Why it mattersAI coding tools have deep access to code and credentials, which makes their extension stores a prime target for supply-chain attacks.

  • GitHub launches Copilot Fusion, which picks the best AI model for each coding task

    At GitHub Universe, GitHub made Copilot Fusion generally available. Developers pick Fusion once, and Copilot sends each task to whichever enabled model fits it best. Artificial Analysis found its top setting used about half the tokens of Claude Code with Opus 5.5 while scoring within two points on coding agent tasks.
    Why it mattersDevelopers no longer have to choose a model for every task, and cheaper routing could put heavy agent use within reach of more teams.
